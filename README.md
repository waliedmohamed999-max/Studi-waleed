# استوديو منتاج 🎬

استوديو مونتاج عربي بالذكاء الاصطناعي، مبني على [Remotion](https://www.remotion.dev).

- **بودكاست بكذا كاميرا**: مزامنة أوتوماتيك من الصوت، وقطع على اللي بيتكلم، وشاشة مقسومة، وريلز طولي.
- **مونتاج أوتوماتيك** لفيديو بتتكلم فيه: قص السكوت والإمم والإعادات، كابشن، زووم، تتبع الوش، لقطات B-roll، ومقاطع ريلز.
- **مخرج الأفلام**: من فكرة لفيلم كامل (سيناريو، شخصيات، صور واقعية، فيديو، تعليق صوتي، حركة شفايف، مزيكا).
- **محرر مشاهد** بطبقات، وقوالب جاهزة، وفيديوهات بالجملة من شيت Excel.
- **تحسين الصوت** بالذكاء الاصطناعي، وتصدير على مقاييس المنصات، ومناطق الأمان، وكابشن النشر.
- **ترجمة ودبلجة بصوتك**، وشيل الخلفية، ودمج كذا كليب، وإيموجي أوتوماتيك، وفلاتر ألوان، وقوالب كابشن وانتقالات احترافية.
- **خطة محتوى** لشهر كامل، ومكتبة ملفات، وقوالبك المحفوظة، ومراجعة الفيديو بالذكاء الاصطناعي قبل التصدير.

## التشغيل

محتاج [Node.js](https://nodejs.org) 22 أو أحدث (والمشروع متجرب على الويندوز).

```bash
npm install
npm run studio
```

الاستوديو بيفتح على `http://localhost:4000`.

## المفاتيح

من جوه الاستوديو: **⚙️ الإعدادات**. تقدر تحط مفاتيح Claude و fal.ai و ElevenLabs و Pexels، وتجربها وتغيرها في أي وقت. المفاتيح بتتحفظ على جهازك بس في ملف `.env` (مش بيترفع على Git). شوف `.env.example`.

من غير مفاتيح، شغّل **وضع التجربة** من الإعدادات وجرّب كل حاجة ببلاش.

## تفريغ الكلام (Whisper)

```bash
npm run whisper
```

بينزّل Whisper والموديل (حوالي 1.6 جيجا) مرة واحدة.

## الاختبارات

```bash
npm test
npm run typecheck
```
